## 本轮变更

- 默认允许外部截图/录屏记录字幕，不再默认施加捕获排除；隐藏时清除排除，
  后台新译文不会给隐藏窗口重新施加排除。可在本应用设置中主动关闭兼容。
- 新配置 Ctrl+Alt+R 框选，避开 NVIDIA 常用 Alt+R；旧保存键值保留，
  请在托盘设置中手动修改。托盘显示实际注册结果及失败提示。
- 框选失焦、异常、取消、捕获丢失及超时清理蒙层，不抢回其他应用焦点。
- 设置仅合并编辑字段，保留最新选区；保存失败不破坏原运行配置。
- 语义符号变化不会被相似度永久忽略；明确输入/模型错误不在静态画面无限
  重试。新候选经 OCR 确认后抑制旧译文，长文在原生调用之间协作取消。
- 两次未识别到文字后提示缩小选区和尝试窗口模式，不冒称检测到 DRM。
- 字幕保持无焦点、鼠标穿透和置顶，不承诺真独占全屏覆盖。
