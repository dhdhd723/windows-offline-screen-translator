# 快捷键录入与清空暂停修订

此修订基于 0.1.1 聊天修订源码；不改变离线模型、原生依赖或已有个人配置。

## 快捷键修改

设置的快捷键栏改为只读显示加“修改”按钮。点击修改、直接按组合键、全部松开，
再保存即可生效，不需要输入 `Alt+T` 等文字。只按修饰键不会完成；裸字母、
不支持的键或重复组合会提示。一个功能只能录入一组修饰键加一个普通键。

按未修饰的 Esc、取消录入、失焦、切换标签或关闭设置，会撤销尚未完成的录入。
已完整录入的值仍是设置窗口中的待保存值，取消整个设置窗口不会写入配置。

仅在录入期间释放本程序的三个全局注册，并暂停本程序的 Esc 轮询。
恢复前等待仍按住的相关键松开，消化已排队的旧快捷键消息，避免录入本身触发翻译。
恢复时使用最新设置；注册失败会提示并同步实际可用按键。退出程序后不会重新注册。
没有增加全局键盘记录、注入或持续收集用户按键的功能。

Windows 保留组合键、其他软件已经注册的组合键不保证可录入或可用。
数字小键盘数字及 AltGr 不作为新录入支持项，避免与实际 Windows 注册键不一致；
主键盘数字、字母、F1–F24 及常用控制键可以配合修饰键录入。

## 清空并停止，一键恢复

默认 Alt+C（或用户自定义清空键）先停止采集，再取消旧结果并清空字幕。
选区、模型和可复用缓存保留，不继续后台识别或自行恢复。
按 Alt+T（或用户自定义启停键）即可在原有效选区恢复，未变化的同一句也可再次翻译。
显示器布局已改变或没有选区时，仍按原有安全规则重新框选。

普通 Alt+T 停止仍保留最后一条字幕；Esc 仅隐藏，不改变监控状态。
托盘和设置中清空动作统一标为“清空并停止”。

## 验证边界

自动测试使用自有 Qt 控件的按下/释放事件、模拟 Windows 注册接口，以及注入
合成画面的真实流水线。打包后的启动自检另含快捷键录入检查，使用随包运行库。
这些检查不等于真实桌面全局按键、游戏或 NVIDIA 录屏验收；未经过的实机场景不标为通过。
