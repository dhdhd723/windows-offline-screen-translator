# 0.1.1 R2 本地候选修订

日期：2026-10-04。不是正式发布；软件版本仍为 0.1.1，通过独立目录和新的
文件摘要区分首轮与 R2，不覆盖首轮候选或已公开的 v0.1.0。

首轮实际 exe 900 秒自建窗口运行通过。但 1800 秒合成画面、真实本地模型
管线长测发现：相同文字的背景动画触发 1 次多余翻译和 40 次重复字幕。
其他检查，包括 60 次双向文字变化和 6 轮清空/停止/恢复通过；长测整体失败，
不降低标准或删除失败记录。有限 32 帧真实 OCR 复现确认，原文字区域像素
完全不变时，上下背景亮度变化也可能造成高置信度的分割误读。

R2 修复目标是：已确认文字区域像素不变且 OCR 近似误读仍在旧文字框内时，
保持可信文字基线；真正文字像素变化或旧框外新增文字仍进入原判断流程。
修复同时覆盖普通识别和慢任务的新原文确认，避免动画误读取消正确结果。
回到原文时清理近似候选计数，避免不连续噪声被累计确认。

R2 的源码回归、真实模型复测、新 exe 构建与运行、ZIP 完整性和隐私审计
必须重新完成。具体通过/失败以随交付的报告与新 SHA-256 为准；不能把旧
候选的通过项或哈希拿来冒称新 exe 已经通过。

NVIDIA 录屏与 Steam 星露谷尚未实测，电脑操作工具初始化故障仍未恢复。
不将自建窗口、合成图片、原生窗口属性或配置文件状态当作游戏/录屏证据。
不注入游戏，不读取存档，不改驱动、安全设置或第三方捕获保护。
