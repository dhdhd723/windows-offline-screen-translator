# 场景预设

2026-10-16。本地候选功能，适用于游戏聊天、阅读、菜单等不同场景。不是按游戏进程自动切换，也不会自动开始截图。

## 保存与使用

1. 在设置中调整需要的翻译、显示、词表、性能和快捷键，点击“保存”使其生效。
2. 托盘右键 →“场景预设…”，或重新打开设置 →“场景预设”→“管理场景预设…”。
3. 选择是否“保存选区及字幕位置”，点击“保存当前设置为新预设…”，输入名称。
4. 以后选择一项，点击“应用所选预设并暂停翻译”。旧字幕被清空，持续翻译停止；按该预设的启停键（默认 Alt+T）恢复。
5. “用当前设置更新所选预设…”覆盖其内容，需确认；重命名不改设置；删除也需确认，不能撤销，但不会改变当前正在用的设置。

预设最多 20 个，名称最多 40 个可见字符。不区分大小写和全角/半角的等价重名不会意外覆盖旧项。
管理器保存的是最新已生效设置，不是其打开时的旧快照，也不保存另一个设置窗口里尚未保存的草稿。
有未保存设置或正在录快捷键时，管理器入口会提示先保存或取消，不悄悄丢弃修改。

## 保存哪些内容

- 翻译方向、连续/逐行排版，聊天词表开关及自定义词义。
- 字号、不透明度、原文显示、Esc 字幕开关、录屏兼容设置。
- 抓屏频率、闲置频率、防抖、OCR 最小间隔、CPU 线程数、磁盘缓存开关。
- 框选/启停/清空三组快捷键；实际是否注册成功仍受系统和其他程序占用影响。
- 勾选时保存选区、显示器标识与物理范围、字幕位置。不勾选则应用时保留最新的当前选区和位置。

开机启动、启动动画、许可确认记录不属于场景设置，始终保留当前值。不会把运行/隐藏状态、截图、OCR 原文、译文或缓存内容装进预设。
最后应用的设置仍通过原 config.json 持久化；重启保持这些设置，但不会因预设自动开启持续翻译。

## 安全切换和边界

- 先验证并保存设置，再停止旧监控、取消旧框选及清空字幕，更新推理参数和快捷键。保存失败时不切换，原运行设置保留。
- 应用成功后总是暂停，不继承“正在翻译”状态，防止切到另一个场景时继续抓错区域；后台旧任务仍受代次检查，不应补回旧字幕。
- 保存的显示器/物理范围不匹配或当前显示器信息无法确认时，旧选区及字幕位置不恢复，提示重新框选，不退回另一个游戏的旧区域。
- 选区保存时为空，应用含选区的预设后也要求框选。若只想换显示或词表设置，请保存时取消选区勾选。
- 游戏窗口位置、界面缩放或文字布局变化，未必能通过显示器信息自动发现。遇到这些变化必须重新框选；预设不是通用游戏识别功能。
- 快捷键冲突沿用已有错误提示/备用框选键策略；设置页和托盘显示实际有效结果，不保证所有程序都让出相同按键。

## 本地存储与隐私

预设在用户数据目录 presets.json 中，与 config.json 分开；程序正常启动只加载当前设置，打开管理器时再读取预设。
通常目录为 %LOCALAPPDATA%/ScreenTranslator，可被诊断专用数据目录覆盖。
原子写入失败保留原文件；损坏、过大或未知版本的文件不会被空白预设覆盖，管理器提示错误并暂停写入。
程序提供刷新列表用于重新读取已修复的文件，不提供本轮尚未实现的跨电脑导入/导出。

预设含个人偏好、自定义词义及可选的屏幕坐标，属于私有数据。发布过滤和 .gitignore 排除 presets.json 及其临时/备份同前缀文件。
不要把用户数据目录、私有日志或缓存上传 GitHub；模型自带 config.json 不属于用户配置，不应误删。

## 验证范围

本轮测试覆盖存储 CRUD、同名/限额、异常和损坏文件保护、场景字段白名单、全局许可/启动状态保留，
以及实际 Qt 管理器、设置入口和应用控制回调的暂停/恢复行为。新 exe 自检使用临时文件和本应用自己的界面，
不操作其他软件、系统快捷键或游戏，不读取个人预设。最终运行包的测试结果在交付报告中记录。
