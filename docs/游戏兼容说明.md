# 游戏、字幕与截图录屏兼容

## 使用要点

1. 优先使用游戏的窗口或无边框窗口模式。普通桌面置顶窗无法保证覆盖真正的独占全屏，本程序不注入游戏，不绕过反作弊或受保护内容。
2. 切换游戏、分辨率或显示器后重新框选，只选清晰菜单或对白，留出选区外的字幕空间。旧选区不是按游戏自动跟随的。
3. 默认 Ctrl+Alt+R 框选，Alt+T 启停，Alt+C 清空并停止。旧配置可能仍保留其他框选键，以托盘或设置显示的实际注册结果为准。
4. 按 Alt+C 后不会再监控或自动重现字幕；Alt+T 恢复原选区并建立新观察，同一句可再次翻译。Esc 隐藏不等于停止捕获，且仍会传给当前程序。
5. 设置中保持“兼容截图和录屏（字幕可以入镜）”开启。关闭此项可能启用系统捕获排除，并可能影响外部录屏；关闭或隐藏字幕后的行为须实际测试。

若无字幕，先从托盘“复制当前译文”判断有无推理结果。有译文但看不到时检查主动隐藏、字幕空间和显示模式；没有译文时检查选区、清晰度和本地捕获。艺术字、极小文字、逐字动画和混合背景都可能影响 OCR。

## 有限本地诊断

开发者或有命令行使用经验的用户可在程序目录运行：

```powershell
.\ScreenTranslator.exe --capture-test --capture-delay 3 --report .\capture-health.json
```

先正常使用程序完成首次条款确认并保存选区；诊断前停止持续翻译、隐藏原字幕，运行后让待测游戏在前台。默认三次采样后退出，最多五次，等待最多十秒。不会自动启动游戏、安装组件、改变选区、写入翻译缓存或自动接受条款。请勿将整屏误选为对白区域。

报告只包含所选区域宽高、像素亮度与近黑/近白占比、变化、OCR 行数/字符数/置信度、方向、译文是否非空及耗时。没有截图、原文、译文、屏幕坐标、窗口标题或个人路径。网络尝试会被 Python 诊断保护阻止；这不是操作系统级防火墙或断网证明。

`completed` 表示这次诊断按流程执行完；`stage_results` 分别说明捕获、OCR 和本地翻译情况。黑色或白色可能只是正常过场/空白选区，不自动判为 API 失败。`overlay_display_tested` 与 `game_compatibility_tested` 固定为 false：这项诊断没有验收字幕显示、译文正确性、独占全屏或录屏保存。

## 当前边界

真实《星露谷物语》的一个中文加载菜单曾确认字幕显示与清空；不能扩展为所有对白或所有显示模式通过。《杀戮尖塔》确认正常菜单、实际捕获非黑帧，但旧选区覆盖艺术标题，正确菜单译文验收尚待完成。《以撒的结合：忏悔》曾出现无法对应游戏文字的字幕，不能标为通过。NVIDIA 实际录制开始、保存和回放尚未完成对照，不宣称占用提示已全部解决。

结果会随测试更新，以交付验收报告为准。本程序不要求关闭安全软件、修改系统隐私权限或使用管理员权限。
