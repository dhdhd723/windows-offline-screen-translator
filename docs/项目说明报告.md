# 本地屏幕中英翻译器：项目说明报告

版本：0.1.0。适用系统：Windows 10 2004 及以上 / Windows 11，64 位。

## 1. 项目用途与交付形式

本项目将屏幕固定区域中的中文或英文识别出来，并在悬浮字幕中显示另一种语言的译文。截图、文字识别和翻译在本机完成，不调用付费翻译 API。适合清晰的窗口文字、短句和字幕，不保证专业术语或复杂上下文的翻译质量。

源码与便携程序是两种不同交付：

- **源码包**：包含程序源码、测试、打包配置和开发文档，不包含 exe、运行组件或模型权重。开发者需要 Python 环境和模型文件。
- **便携包**：包含 exe、运行组件、本地模型及许可证，完整解压后可运行，普通用户无需安装 Python、Visual Studio 或显卡环境。本轮已重建同版本纯 CPU CTranslate2，关闭 CUDA/cuDNN/MKL，使用 oneDNN CPU INT8 与微软 OpenMP；不再使用旧 Intel/CUDA 候选二进制。作者个人 Community 发行路径、官方未修改运行库及首次用户保护条款已经落实；Qt/GEOS/MPL 的对应源码与原许可证实际随包保留。升级原生依赖后必须重新核验。

准备开发依赖与下载模型通常需要联网；模型准备完成后，应用的截图、OCR 和翻译链路可以离线运行。离线运行不代表模型文件无需事先准备。

## 2. 已实现的功能与操作

| 操作 | 默认快捷键 | 行为 |
| --- | --- | --- |
| 框选区域 | Alt+R | 拖动鼠标保存固定翻译区域；框选时 Esc 或右键取消。 |
| 持续翻译 | Alt+T | 开启或停止监控；文字变化后自动识别和中英互译。停止后保留最后字幕。 |
| 清空字幕 | Alt+C | 清除当前译文，未变化的原句不会立即重新出现。 |
| 隐藏／恢复 | Esc | 临时隐藏或恢复字幕，不改变监控开关；Esc 仍传递给当前应用。 |

程序提供无边框、置顶、半透明、不抢焦点的悬浮字幕，默认鼠标穿透。托盘菜单支持框选、启停、清空、隐藏、复制完整译文、设置和退出。字号、透明度、翻译方向和快捷键可以调整。

Alt+R 被占用时，程序依次尝试 Alt+Shift+R、Ctrl+Alt+R，以托盘提示的实际按键为准。Esc 的全局观察可在设置中禁用。

可以在任意显示器上选择区域，但当前只支持一个固定区域，且选区必须完全位于同一显示器内。显示器布局或分辨率变化后需要重新框选。

## 3. 技术实现

界面使用 PySide6 Widgets，Windows 集成使用 Win32 API，固定区域截图使用 MSS。OCR 使用 RapidOCR 与 PP-OCRv5 mobile ONNX 模型；中英翻译使用两个方向的 OPUS-MT 模型，转换为 CTranslate2 INT8，配合 SentencePiece 分词。

纯 CPU CTranslate2 4.8.2 与 oneDNN 3.1.1 在 Windows 上从固定源码重建，
支持 `float32`、`int8`、`int8_float32`。121 个原生文件检查未见
Intel OpenMP/MKL/CUDA/cuDNN/FFmpeg 依赖或相应运行二进制，构建配置也明确
关闭这些后端。17 份 v14 副本均与官方未修改原件哈希匹配；Windows 10/11
自带 UCRT/API-set 使用系统实现，不重复打入包。详细哈希见
[CPU 构建记录](CPU_BUILD_PROVENANCE.md) 与 [微软核验](MICROSOFT_RUNTIME_TERMS.md)。

界面、截图和推理分别处理，避免 OCR 或模型加载阻塞界面。待处理队列只保留最新画面，防止累积过时任务。图像变化检测、防抖、文本相似度判断与精确翻译缓存共同减少重复处理；启停或清空后，旧任务不得重新发布字幕。

运行包采用 PyInstaller 目录形式打包，避免每次启动解压大模型。PyTorch 与 Transformers 用于模型准备，不进入应用运行链路。更详细的模块、线程和数据流见 [技术方案](技术方案.md)。

## 4. 隐私与数据保存

默认不保存屏幕截图，不将识别原文写入运行日志，译文缓存只存在内存。设置保存在 `%LOCALAPPDATA%\ScreenTranslator\config.json`。主动开启磁盘缓存后，SQLite 数据库会保存译文；关闭选项不会自动删除已有数据库。

公开源码导出排除用户设置、译文数据库、截图、原始测试报告、日志、虚拟环境、构建缓存及原 Git 历史，并保留必要的第三方署名和许可证。`.gitignore` 只能辅助防止误提交，不能清除已提交的敏感内容。文件脱敏也不会隐藏发布者的 GitHub 账号或提交身份。详见 [发布与隐私说明](PUBLISHING.md)。

主要限制：

- 不支持跨屏选区、多区域监控或字幕历史。
- 小字、艺术字体、运动背景、逐字字幕和混合语言可能影响识别与方向判断。
- 专业术语、口语和孤立短词的译文不保证准确。
- DRM 保护内容、独占全屏和安全桌面可能无法捕获。
- 混合 DPI、多种游戏和长时间运行仍需进一步人工测试；不承诺统一的延迟或资源占用数值。
