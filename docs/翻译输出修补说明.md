# 翻译输出修补说明

日期：2026-10-14。此修订是 0.1.1 的本地候选，不是已经验收的正式发布。

针对反馈中的繁体字、长段落漏掉后句、已知名称被直译及游戏习语误译，本轮修改翻译前后的处理，不更换现有离线模型、不调用联网翻译服务。快捷键录入、清空并停止／恢复、启动卡片及聊天缩写功能保持现有行为。

## 本轮改动

| 问题 | 处理方式 | 不代表什么 |
|---|---|---|
| 英译中出现繁体或繁简混用 | 新译文正文按固定版本 OpenCC 1.1.9 官方 `t2s` 词典转换一次，再写入缓存 | 字形转换不会修复词义、语法或文风 |
| 多句段落只返回前半段 | 按完整句子依序提交模型，再合并为原段落；超长单句仍受原有分块与长度限制保护 | 每句被提交不保证模型内部绝不漏译 |
| 游戏名、开发商名被机械直译 | 少量已确认名称在明确语境下独立处理；未知名称不猜测 | 不是通用专名识别，也不是通用游戏汉化词库 |
| `keep you on your toes` 在游戏介绍中被译成“保持脚趾” | 有游戏／沉浸／灵异等线索且无舞蹈等反向线索时，将源文表达改为 `keep you alert` 再翻译 | 没有在所有译文中机械替换“脚趾”，其他习语仍可能错译 |
| 字幕提示“原文截断”容易误解 | 原文预览提示改为“原文仅显示部分” | 这只是字幕预览的显示范围，不表示翻译输入被裁掉 |

分句不制造新的聊天消息，也不打乱消息行顺序。逐行对话模式继续保留独立行；连续文本模式仍将普通软换行视为同一段落。标点、缩写、版本号、网址等采用保守判断；原文没有明确句界时，不保证能恢复完整段落结构。

简体处理只作用于新生成的英译中正文：不改 OCR 原文，不把用户名、昵称一并转为简体，不改中文→英文结果。缓存身份包含字形、分句及术语策略，旧策略结果不继续命中；缓存读取不重复转换，避免官方词典的少数短语发生二次改写。词典随程序编译，不增加 DLL；词典版本和许可见[OpenCC 词典说明](OpenCC词典说明.md)。

## 专名规则的范围

- `Red Barrels` 在开发商或游戏介绍线索明确时保留英文，`Murkoff` 在对应公司、试验或治疗语境中保留英文，避免猜测未经核对的中文名称。
- `Phasmophobia` 在独立标题行或明确游戏／灵异调查语境中使用《恐鬼症》；临床、诊断、疾病定义等线索阻止覆盖普通词义。
- 已有《星露谷物语》《空洞骑士》《杀戮尖塔》独立标题规则保留；行内只有明确的游戏／游玩语境才处理，地点或普通词义不套用游戏名。
- 明确的 `Peppa's World`／`Peppa’s World` 片段使用“佩奇的世界”；周边普通文字仍交给模型。裸昵称、宠物名或未知完整标题不强行改写。
- 精确的 `Immersive Experience:` 标题使用“沉浸式体验：”；不将任意包含 `experience` 的句子改成这个标题。

规则大小写、链接、代码、普通词义和反向语境的边界见[受控翻译术语](受控翻译术语.md)。这是针对可确认问题的小范围修补，不是背诵整张反馈图片或整段商店介绍。

## 测试与验收边界

冻结源码前已完成以下本机检查：

- 源代码回归：2503 项通过、4 项跳过、6 项排除。包含快捷键录入、清空／停止／恢复、聊天分行、缓存、启动卡片与新输出策略；不等于全部测试或物理按键实测。
- 原生 CPU 离线模型自检：生成图像 OCR、中英双向翻译、原有 11 项标题／署名及聊天固定语料检查通过；Python 连接尝试为零。
- 新输出策略的 5 组固定文本检查与字形例外检查通过；另对 11 组公开固定文本各运行两次，输出一致。
- 更宽泛的旧语义关键词检查仅 4/8 通过，失败项仍保留，没有用“所需范围通过”掩盖普通菜单、地点和口语错译。

这些检查只证明本轮局部处理生效：`Join Peppa's World` 得到“加入佩奇的世界”；已知习语得到“保持警觉”；恐鬼症介绍的最后一句被单独提交并产生译文。但最后一句仍有“困扰自己的一部分”等不自然表达，工作室例句也仍遗漏“邀请”的含义。这不是整体翻译质量验收通过。

当前文档不宣称 Windows 完整包已通过本轮验收。构建后需核对 exe 与源码绑定、模型和原生运行组件保持不变、第三方许可齐全，并运行离线固定文本自检。验收应同时检查最后一句确实进入模型、消息行未合并、昵称未改写、新缓存不沿用旧错译以及中→英不被简体处理干扰；运行包最终检查结果另行交付，不修改冻结源码来追写结论。

本轮未进行真实游戏画面、NVIDIA 录像、多显示器／DPI 或物理按键的实机验收；固定文本和离屏窗口测试不能代替这些测试。用户反馈图片及原始私人路径不随源码或运行包分发，也不上传外部服务。

已知限制仍在：原有小型离线模型可能产生僵硬表达、局部漏译、重复或语义错误；切句和保护名称有时会减少上下文、使句子衔接不自然。简体字形正确、标题正确、最后一句被提交，都不等同于整段翻译自然准确。本轮不承诺解决全部反馈，也不把更换大模型悄悄加入此修订。

## 试用方式

使用本轮重新构建的完整 Windows ZIP，退出旧版后解压到新目录，保留 `_internal`、`models` 和 `LICENSES`，再启动新 exe。仅替换源码、仅复制 exe 或下载 GitHub 自动生成的源码 ZIP，不能更新完整运行包。此修订不自动上传 GitHub；本地验收通过后再决定发布。
