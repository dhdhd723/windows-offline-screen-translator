# 本地屏幕中英翻译器使用说明

版本：0.1.1 候选，待验收。旧版 0.1.0 的下载附件保持不变，本说明不代表
0.1.1 已公开或已通过 Steam/NVIDIA 实机测试。见 [本轮验收说明](0.1.1验收说明.md)。

适用系统：Windows 10 2004 及以上 / Windows 11，64 位。请下载完整 Windows 运行 ZIP，完整解压后双击 `ScreenTranslator.exe`；不要拆开或单独移动 `_internal`、`models`、`LICENSES` 文件夹。GitHub 的 Code → Download ZIP 是源码，不是普通用户运行包。不需要安装 Python、显卡环境或使用付费 API。

程序尚未做数字签名。首次启动可能出现系统安全提示；请核对来源和发布校验码，不需要关闭杀毒软件或使用管理员权限。

首次正常启动会显示微软运行库使用条款。须阅读、勾选确认并点击“同意并启动”
后，才会注册全局快捷键和启用监控；不同意会退出。确认仅保存在本机设置，
不发送给第三方。该条款不削弱 Qt、GEOS、Eigen 等组件各自的开源许可权利。

## 操作

| 操作 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 框选区域 | Ctrl+Alt+R | 新配置的默认键；旧配置以托盘实际按键为准。拖动鼠标保存固定选区；框选时按 Esc 或右键可取消。 |
| 开启／停止 | Alt+T | 文字变化后自动 OCR 和中英互译；停止后保留最后字幕。 |
| 清空字幕 | Alt+C | 清空当前译文，同一段未变化的文字不会立即重新出现。 |
| 隐藏／恢复 | Esc | 临时隐藏或恢复字幕，不改变监控开关；Esc 仍传给当前应用。 |

程序常驻系统托盘，可从托盘完成框选、启停、清空、隐藏、复制完整译文、设置及退出。若没看到图标，请展开托盘的隐藏图标。

新配置的默认框选键为 Ctrl+Alt+R。升级会保留已有配置中的快捷键，不会
自动把 Alt+R 或 Alt+Shift+R 改掉；请从托盘“设置”手动修改。按键仍可能
被其他程序占用，请以托盘提示为准；无反应时先用托盘菜单，不要修改其他
软件或以管理员权限强行抢占。全局 Esc 可在设置中禁用。

可以在任意显示器上框选，但一次选区必须位于同一显示器内，不支持跨屏选区。显示器布局或分辨率改变后，请重新框选。字幕默认置顶、半透明、鼠标穿透且不抢焦点；框选和设置窗口正常接受输入。

首次翻译需要加载本地模型，后续相同文字可复用缓存。建议只框选一两行清晰字幕，避免大范围画面、运动背景及极小字号。受 DRM 保护的画面、真独占全屏和安全桌面可能无法捕获，真独占全屏也可能遮住普通字幕窗；游戏优先使用普通窗口或无边框窗口。

2026-10-08 本地候选在抓屏接口持续报错时先短暂重试，再每 5 秒等待恢复；
等待期间不进行 OCR 或重新加载模型，恢复后自动继续监控。按 Alt+T 或从
托盘停止会立即取消等待，不会自行重新启动。Alt+C 清空的未变化文字也不会
因为恢复而重新出现。如果显示器身份、布局或选区已确认改变，程序仍停止并
要求重新框选，不把原坐标自动挪到其他屏幕。详见 [捕获恢复修订说明](捕获恢复修订说明.md)。

## 聊天与 Roblox 的逐行对话

从托盘“设置”→“显示与翻译”→“文字排版”选择“逐行对话（聊天／Roblox）”，
保存后按识别出的上下行分别翻译，并保留译文行顺序。适合两条独立聊天消息，
可避免将它们合成同一句；这是按 OCR 识别行处理，不保证自动判断不同发言人。

如果同一句话只是因为对话框较窄而自动折成两行，应选择默认的
“连续文本（段落／长句）”，让整句保留上下文。旧配置升级仍默认连续文本，
不会自动改变原有翻译方式。该修订需重新构建运行包；旧 exe 不会出现新选项。
Roblox 实际聊天画面的识别与译文质量仍需实机验收。

### 聊天缩写词表

在“设置”→“聊天词表”可启用或关闭，默认启用；**英文 → 中文的两种排版均生效**。
独立消息 `ty` / `tys` 直接显示 `谢谢`，`np` 显示 `没问题`；长句中的缩写仍先英文展开再翻译。
明确的 `昵称: 正文` 只翻译正文，昵称保留；未知缩写和普通口语仍可能错译。
内置 40 项，不需要自己逐条添加；自定义词表可以保持空白。
在“内置词表”分页可直接查看全部项，“自定义（可选）”只用于补充或覆盖特殊用法。
新增项包括 `ngl`、`btw`、`wdym`、`omw`、`nvm`、`gg` 等，完整词表和核对依据见
[聊天内置词表](聊天内置词表.md)。这不是所有社区通用的词义标准，遇到不同用法可通过自定义项覆盖。

自定义词表每行填写 `abbreviation = expansion`，例如：

```text
tys = thanks
np = no problem
```

最多 100 条；缩写仅含英文字母、数字且以字母开头，最长 24 位，不区分大小写。
英文展开最长 160 字符，只允许可打印 ASCII 字符且至少含一个英文字母，不允许中文、控制字符或换行。
保存时会提示无效行与重复缩写。留空词表仍使用内置项；移除自定义项会恢复相应内置含义，
不能通过空值删除内置词。关闭开关不会丢失已填的自定义词表。

展开仅用于翻译输入，不修改显示的识别原文，也不合并上下行；可识别的用户名和网址会避开展开。
未命中的内容照常交给本地模型。这不是 OCR 自动纠错，OCR 误识别仍可能使缩写无法命中。
自定义项保存在本机设置文件，发布源码和运行包时不要混入个人配置。

## 录屏与星露谷物语

设置中的“录屏兼容”默认开启（`recording_compatibility=true`）。开启时
本应用字幕允许出现在其他截图、录像和共享屏幕中，不启用 Windows 字幕
捕获排除；不要误以为字幕仍会在所有录像中隐藏。关闭该选项才尝试排除
字幕，捕获保护可能与某些录屏工具冲突。这里只控制本应用窗口，不绕过
DRM，也不修改游戏、NVIDIA 设置或驱动。

将悬浮字幕放在选区外。如果字幕与选区重叠且不能排除捕获，程序会避免
显示重叠字幕，防止自己的译文被反复识别；可从托盘复制结果。

星露谷可在游戏内 Options → Graphics → Window Mode 选择
Windowed Borderless（无边框窗口），显示铺满屏幕但仍是窗口模式；也可
先用 Windowed（普通窗口）排查。改变模式、分辨率或 UI 缩放后重新框选。
这是兼容性建议，**不是全屏已经支持的承诺**：用户反馈旧版 Fullscreen
完全没有译文，本轮 Steam 星露谷与 NVIDIA 录屏仍未完成实机验收。
依据：[星露谷官方 Wiki](https://wiki.stardewvalley.net/Options)、
[Microsoft 全屏呈现说明](https://devblogs.microsoft.com/directx/demystifying-full-screen-optimizations/)。

## 隐私与故障

截图、OCR 和翻译都在本机处理。默认不保存截图，识别原文不写入运行日志，译文缓存只存在内存。设置保存在 `%LOCALAPPDATA%\ScreenTranslator\config.json`。若主动开启磁盘译文缓存，缓存数据库会保存译文；关闭选项不会删除已有数据库。

不要把运行后的配置、缓存、截图或原始诊断日志直接上传到公开仓库。公开文件的准备方法见 [发布与隐私说明](PUBLISHING.md)。录屏兼容开启时，外部录屏可能记录译文及屏幕内容，请自己控制共享范围。

快捷键无反应时先查看托盘提示或使用托盘菜单。黑屏时尝试切换窗口模式并重新框选。字幕与选区重叠且无法排除捕获时，程序会隐藏字幕以防循环识别，此时仍可从托盘复制译文。

发布程序支持 `--self-test --report 报告路径.json`，使用生成的测试文字验证离线 OCR 和两个翻译方向，不读取用户屏幕。`--smoke-test` 可检查初始化后自动退出。真实硬件、游戏和 DPI 的兼容性仍需在自己的设备上验证。

诊断需要已接受随包条款；否则退出码为 3。明确阅读并授权自动验收后，可以
在这两种诊断模式中加 `--accept-runtime-terms`。不要将验收产生的个人设置或
接受记录混入公开包。
