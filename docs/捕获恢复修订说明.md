# 捕获恢复修订说明

日期：2026-10-08；版本：0.1.1 本地候选修订。需使用本次重新打包的完整运行包；旧 exe 不会随源码修改而自动更新。

本次只调整屏幕捕获异常恢复与选区有效性判断，不调整 NVIDIA 录屏兼容设置、字幕窗口样式、翻译模型或聊天词表。

## 行为

- 正常捕获沿用已有抓屏、去重、OCR 和翻译节奏。
- 暂时性本机捕获异常先进行 0.15、0.30、0.60 秒的快速重试；继续失败时，在原捕获线程中每 5 秒探测一次，直到屏幕恢复或用户停止。
- 等待时保持用户的监控开启意图，但不向 OCR 提交新帧、不反复加载模型、不创建恢复定时器或新的恢复线程。失败后端在等待前关闭，恢复时在所属线程重建。
- 主动停止、退出和重新选区会取消旧会话；过期 OCR／译文不能作为新字幕发布。清空后的相同文字不会因恢复重新出现。
- 暂时没有显示器信息或任一显示器信息读取失败，不算确认的布局改变；主界面的显示器定时检查也不会因此取消恢复。
- 一旦完整信息确认原显示器身份、范围或区域已经改变，停止并要求重新框选；抓屏前逐次验证，不擅自抓取其他显示器。
- 非捕获错误、非法帧仍停止并报告；黑屏或白屏本身不作为接口故障，也不自动更换捕获方式。
- 异常日志限频，避免持续失败时每次重试都写完整异常堆栈。托盘显示正在重试或等待恢复，仍可主动停止。

## 验证边界

自动测试通过注入本机捕获异常，覆盖超过原三次上限后恢复、等待频率、资源释放、真正 5 秒等待的快速取消、清空／旧译文隔离和显示器临时不可读的应用定时检查。

本次不人为让用户电脑睡眠或锁屏，不将异常注入测试写成所有实际睡眠／驱动／游戏情形已通过。真实 NVIDIA 同时录制、独占全屏覆盖和 Roblox 现场聊天验收仍是独立事项。本地候选不自动上传到 GitHub，也不覆盖旧运行包。
