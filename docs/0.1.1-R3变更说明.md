# 0.1.1 R3 候选变更与边界

2026-10-04。版本号仍为 0.1.1，以独立目录、候选修订和实际文件摘要区分；旧 R2 包不覆盖。当前发布状态仍为 pending，不自动替换 GitHub 正式版本。

## 修复与诊断

- 保存修正后的设置时，会重新安全显示因兼容策略或选区重叠而自动隐藏的保留字幕；用户主动隐藏、框选中和空译文不会被擅自显示。
- 真实 MSS 捕获发生已知暂时错误时，先撤销过期任务、关闭原采集资源，再最多进行三次可中断重建；停止可打断退避。无效帧、尺寸不符或意外错误仍停止，不无限重试。
- 采集资源仅在拥有线程关闭，关闭幂等；恢复后重新建立观察基线，保留 Alt+C 清空抑制，避免旧译文回流。
- 新增显式本地 `--capture-test`：有限采样真实 MSS、OCR 和本地翻译，报告仅含像素统计、文字数量、方向、耗时和阶段状态，不保存截图、原文、译文、坐标、窗口标题或截图摘要，不开启托盘监控或修改选区。
- 公开包说明链接从实际导出的文档生成，修复 R2 及后续说明在便携包根目录中的导航。

保持原纯 CPU 依赖、离线模型、MSS GDI 后端和默认截图/录屏兼容策略；没有增加 DXGI 采集会话、游戏注入、驱动或联网翻译。

## 实机证据的解释

用户确认《杀戮尖塔》实际显示正常菜单；此前电脑操作工具的窗口黑图不是游戏黑屏证明，也不代表翻译器 MSS 黑帧。重新激活后工具已读到正常菜单。

使用原有选区的一次真实 R2 试验显示了字幕，但区域主要覆盖艺术字标题，识别与翻译不准确，不能当作菜单文字翻译通过。R3 开发诊断对同一选区三次实际 MSS 采样均获得非黑图像、OCR 文字和非空本地翻译；报告不保留文字。这仅是捕获与推理阶段证据，不证明文字正确或字幕显示通过。应只选择清晰菜单/对白，不识别整块艺术字标题。

最终 R3 单测、长时运行、打包、隐私和实机结果以其独立交付验收报告为准，不沿用 R2 摘要作为 R3 证明。真实游戏动态对白、显示模式、物理拖选、多屏混合 DPI、NVIDIA 录制与干净 Windows 仍需取得各自证据。
