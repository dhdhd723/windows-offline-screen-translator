# 聊天缩写增补与测试说明

日期：2026-10-15。Windows x64 本地候选包，应用版本仍为 0.1.1；聊天词表和翻译策略版本均为 3。
本次已完成词表增补、源码回归、新 exe 构建、完整解压校验及解压后的 exe 离线自检。
本报告随 GitHub 独立预发布提供；2026-10-15 为构建与测试日期，2026-10-16 进行发布，实际可下载状态以发布页为准。

## 新增和保留

原有 40 项保留，新增 18 项：sm1、l8r、cya、cyaa、prolly、cuz、bc、ppl、pic、rn、fr、hbu、yk、def、istg、tytl、mdfk、asf。
pls、thx、BTW、TBH、IMO、IDK、LOL、BRB、OMG、WYD、NGL 等已存在，不重复计算。
TYTL 按用户本轮确认兼容为“回头聊”，并保留常见 TTYL；不进行通用拼写纠错。

新增项同时具有英文展开和独立中文短回复：例如 `sm1` → `有人`、`RN` → `现在`、`HBU` → `你呢`、`ISTG` → `我发誓`。
两种排版均生效，默认开启，无需逐条手填；自定义优先，原始 OCR 显示不改写，明确昵称保持原样。
旧词表策略的错误缓存不会用于新策略，无需删除用户配置或整个缓存。

数字 `2` 不是无条件的 to：例如 `I want 2 play with 2 ppl` 展开为 `I want to play with 2 people`。
`2 players`、`level 2`、`go 2 miles`、时间和版本号等保持数字。规则仅覆盖文档列出的固定上下文。

MDFK 采用 motherfucker 的粗俗聊天含义，依据是社区投稿而非权威通用定义；ASF 是粗俗的程度强调。
有限的形容词后缀（如 `tired asf`）规范化为 `extremely tired` 再翻译，减少逐字误译；独立回复明确标注粗俗语气。
RN/FR/BC/DEF 等也有医疗、地域、技术等含义，不能全场景自动消歧；不适用时关闭聊天词表或自定义覆盖。

全部词义、英文展开、资料链接和边界见源码包内 `docs/聊天内置词表.md`。
本轮参考 Cambridge、Collins、Dictionary.com、NetLingo 等公开资料及原始语料，没有复制第三方项目代码，也没有运行时联网查词。

## 已知问题，未作通过承诺

- 小写 `l8r` 在固定图像里被 OCR 识别成 `18r`，句中还观察到 `I8r`。词表能正确处理识别正确的 `l8r/L8R`，但不盲猜改写 `18r/I8r`；大写样本通过不代表所有字体可靠。
- 9 个长句探测中，`send a pic rn` 出现过 OCR 重复 a，`I will prolly join l8r` 存在漏空格和 l/I 混淆；原始探测结果仅在本地保留，不随公开附件分发。
- 小模型长句质量没有整体解决。例如 `I need 2 go` 的译文有重复，`this is cool asf` 仍可能生成“这酷酷酷极了”。既有扩展语义关键词检查仍为 4/8，不把“exe 自检通过”当作所有翻译正确。
- 本轮未完成 Roblox 实机、NVIDIA 录屏、真独占全屏、物理快捷键和无开发环境的全新 Windows 验收；这是可运行的本地候选，不是所有游戏已验收的正式发布。
- 扫描只能证明所检查范围内未发现信息泄漏，不是隐私与许可的绝对保证。不要把 private/、validation/ 或测试日志一并公开。

## 使用

退出旧版，完整解压新的 Windows 压缩包，再运行 ScreenTranslator 文件夹内的 ScreenTranslator.exe。
不要只复制 exe；同目录的 `_internal`、`models`、`LICENSES` 等需一起保留。普通用户无需安装 Python。
在设置的“聊天词表”页确认显示“已内置 58 条”；原有自定义会继续覆盖内置含义。
如果同一缩写仍显示旧含义，先检查是否实际启动了旧 exe 或存在旧自定义覆盖，不必删除全部设置。
