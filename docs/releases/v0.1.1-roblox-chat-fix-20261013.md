# 0.1.1 Roblox 聊天修补预发布版

请下载附件 **ScreenTranslator-0.1.1-Windows-x64-candidate.zip**，不是 GitHub 自动生成的 Source code ZIP。
完整包包含 exe、模型、运行库和许可文件，无需安装 Python，不使用付费翻译 API。
退出旧版，将完整 ZIP 解压到新文件夹，运行 `ScreenTranslator/ScreenTranslator.exe`，不要只复制 exe。
首次运行仍须阅读并明确同意随包运行库条款。

## 本次修复

- 聊天词表开启且英文 → 中文时，连续文本和逐行对话均生效，不必先切换模式。
- 内置 40 个缩写独立成消息时直接显示中文：`ty` / `TY` → `谢谢`、`np` → `没问题`；长句仍先展开再交给本地模型。
- 明确的 `昵称: 正文` 保留昵称，只翻译正文，避免昵称污染模型输出。
- 聊天 `昵称: take lead` 显示为 `昵称: 带头`；不对所有 `lead` 做全局替换。
- 两条有明确昵称前缀的消息保留分行；普通段落软换行仍按原布局处理。
- 自定义规则仍优先，旧错误缓存不被新策略复用；清空、停止与文字更新的取消检查保留。
- 保留约 2 秒启动动画及结束后自动打开设置、原有标题术语修补和 `dhdhd723` 署名标记。

新配置框选快捷键为 Ctrl+Alt+R；Alt+T 开启／停止，Alt+C 清空，Esc 隐藏／恢复。
已有配置保留原快捷键，请以托盘设置显示为准。聊天词表开关需保持开启。

## 尚未验收和质量限制

**这是预发布版，不是 Roblox 实时聊天、全屏字幕或 NVIDIA 录制已经验收的正式版。**
截图复查和离屏自检不等于重新进入游戏的实时显示测试，也不等于全新 Windows 系统验收。
未知 `oms` 没有未经确认的释义；普通口语、双关和非标准表达仍可能翻错。
普通菜单／对白的扩展检查仍是 3/8，不能把本次规则修补当成模型整体准确率提升。
署名标记能保留来源线索，不能防止他人删除标记或复制代码。

Windows 10 2004 及以上／Windows 11，64 位。发布前请核对附件 `SHA256SUMS.txt`。
`ScreenTranslator-0.1.1-source.zip` 是与运行包对应的核验源码；仓库另有本次下载导航和发布说明。
