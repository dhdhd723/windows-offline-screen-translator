# 场景预设交付与测试说明

日期：2026-10-16。Windows x64 候选，程序版本仍为 0.1.1。本报告随独立预发布标签 `v0.1.1-scene-presets-20261016` 提供；旧版本、标签和运行包不覆盖。它不表示正式稳定版已获批准。

## 已完成

新增“场景预设…”管理器，托盘菜单和设置的“场景预设”页均可进入。
支持保存、应用、用当前设置更新、重命名及确认后删除；最多 20 项，名称最多 40 个可见字符。
内置聊天词表 58 项、按键录入、清空并停止及约 2 秒启动动画等现有功能保留。

预设保存已生效的翻译、显示、聊天词表、性能、缓存开关和快捷键；可选保存选区及字幕位置。
开机启动、启动动画和许可确认记录仍使用最新全局值，不会被场景快照覆盖。
应用成功会取消旧框选、停止翻译并清空旧字幕，按该预设的启停键恢复；不自动继续抓屏。
选区不随预设保存时保留当前区域；保存的区域因显示器变化不可确认时清除并提示重新框选。

个人预设单独存于用户数据目录 presets.json，无截图、识别原文、译文或缓存内容。
使用原子写入；无法保存则不切换运行设置。损坏、过大、重复字段或未知版本的预设文件不会被空白文件覆盖。
发布过滤和 Git 忽略规则排除个人预设及其临时/备份文件。

## 使用

1. 退出旧版，完整解压新的 Windows ZIP，运行 ScreenTranslator 文件夹内的 ScreenTranslator.exe。不要只复制 exe。
2. 调整设置后先点击“保存”。有未保存草稿或正在录快捷键时，场景预设入口会提示先处理，不会悄悄丢弃修改。
3. 托盘 →“场景预设…”→“保存当前设置为新预设…”，按需要勾选是否保存区域。
4. 切换时选中预设并应用，再按当前启停键（默认 Alt+T）恢复翻译。

详细行为与数据边界见源码内 docs/场景预设说明.md。程序不是按进程自动切换的游戏识别器。
游戏窗口移动、文字布局或界面缩放变化不一定能由显示器坐标检测发现，应重新框选。
快捷键占用仍以托盘显示为准。原有 l8r OCR 混淆和长句重复/错译未在本次修复，扩展语义关键词范围仍为 4/8。
