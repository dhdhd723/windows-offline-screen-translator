# 0.1.1 日语增强预发布版

普通用户下载 **ScreenTranslator-0.1.1-Japanese-Windows-x64-lossless.7z**（791,090,913 字节，约 791 MB），完整解压后运行 `ScreenTranslator/ScreenTranslator.exe`。
包含中英和日语本地模型、运行依赖、许可通知与对应源码档案，无需 Python、显卡环境或付费 API。
系统不能打开 7z 时可使用 [7-Zip 官方工具](https://www.7-zip.org/download.html)。退出旧版后解压到新目录，保留所有随包文件，不要只复制 exe；首次运行须阅读并确认随包运行库条款。

## 更新内容

- 新增手动“日语 → 简体中文”，在设置 →“显示与翻译”→“翻译方向”选择并保存。
- 原中英互译、聊天缩写、快捷键按键录入、清空并停止、两秒启动界面和场景预设保留。
- 日语方向可随场景预设保存。自动模式仍只判断中英，不包含中文转日语、日语转英文或三语自动切换。
- 复用本地 OCR；日语翻译使用固定版本 M2M100 的 CTranslate2 INT8 模型，运行时不新增 PyTorch 或 Transformers。
- 切换语言时在后台释放另一类模型，首次使用或切回可能等待加载；缺失模型会提示，不会自动联网下载。
- 无损压缩从原始 840.3 MB ZIP 降为 791.1 MB 7z，减少约 49.2 MB（5.86%）；全部 695 个文件保持一致，没有删语言、降低精度或移除许可和对应源码。

解压后文件总字节数约 1.095 GB。本次压缩不改变运行内存或模型翻译质量。
若只需中英，可继续下载[之前约 379 MB 的场景预设版](https://github.com/dhdhd723/windows-offline-screen-translator/releases/tag/v0.1.1-scene-presets-20261016)，旧版和附件均保留。

## 使用

新配置默认 Ctrl+Alt+R 框选，Alt+T 开启／停止，Alt+C 清空并停止，Esc 隐藏／恢复字幕；升级保留旧按键，以设置页为准。
两条独立消息使用逐行模式，一句话自动折行使用连续模式。应用场景预设后需手动开启监控。

## 已知问题与未测范围

**这是候选预发布版，不是已完成真实游戏和所有 Windows 设备验收的正式版。**
日语短句也会有语义或措辞错误：“ここで待ってください。”曾输出“请等到这里。”，游戏“物品”也可能译成“项目”。关键词通过不等于完整语义正确。
原中英扩展语义关键词观察仍为 4/8，普通长句、网络口语和 OCR 混淆仍可能出错。
竖排、注音小字、艺术字、昵称及混杂语言无可靠支持承诺。
没有完成真实日文游戏、Roblox 实时聊天、NVIDIA 录制、真独占全屏、混合 DPI 多屏或干净 Windows 的本版实机验收。
优先使用普通窗口或无边框窗口；压缩不修复全屏叠加和录屏兼容问题。

目标 Windows 10 2004 及以上 / Windows 11，64 位。程序未数字签名，可核对 `SHA256SUMS.txt`，不要关闭安全软件。
