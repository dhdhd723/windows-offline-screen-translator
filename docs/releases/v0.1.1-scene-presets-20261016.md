# 0.1.1 场景预设（预发布）

在游戏聊天、网页段落和菜单之间切换时，可以保存各自的设置，不必每次重新调整。
本次程序版本仍为 0.1.1，独立标签为 `v0.1.1-scene-presets-20261016`。这是候选包，不是正式稳定版批准。

## 下载与运行

普通用户下载附件 `ScreenTranslator-0.1.1-Windows-x64-candidate.zip`，完整解压后运行
`ScreenTranslator/ScreenTranslator.exe`。包内包含本地模型与运行依赖，不需要安装 Python、配置显卡或使用付费 API。
保留 `_internal`、`models` 和 `LICENSES` 文件夹。不要只复制 exe，也不要把 GitHub 自动生成的 Source code ZIP 当成运行包。
先从托盘退出旧版，再将新包解压到新目录。首次启动需阅读并确认随包微软运行库条款；不同意会退出。

## 本次更新

- 托盘“场景预设…”和设置的同名页可打开预设管理器，支持保存、应用、更新、重命名和删除。
- 最多保存 20 项，每项名称最多 40 个可见字符。保存的是已经生效的设置，未保存草稿需要先处理。
- 可保存翻译方向、排版、聊天词表及自定义项、字幕样式、性能、缓存开关和快捷键；选区及字幕位置可选。
- 应用后清空旧字幕并暂停监控，按当前启停键恢复。未保存空间坐标时保留当前区域；保存的区域失效时清除并提示重新框选。
- 开机启动、启动动画和许可记录保留当前全局值，不会被预设覆盖。不会按游戏进程自动切换，也不会自动开始抓屏。
- 个人预设只保存在本机 `presets.json`。写入失败不会切换配置，损坏或未知版本的文件不会被空白内容覆盖；发布包不包含个人预设。

保留 58 项内置聊天缩写、快捷键按键录入、清空并暂停、约 2 秒启动动画、离线简体字形转换及保守 OCR 局部重识别。
本次没有更换 OCR/翻译模型、原生运行库或许可文件，没有新增原生依赖。

## 验证范围

100 项预设专项测试通过；最终冻结源码回归为 3,576 项通过、4 项跳过、6 项排除，跳过和排除不算通过。
新 exe 的 7 项预设自检、116 项词表短回复检查、42 项固定合成图像 OCR 管线检查及原有双向离线自检通过。
680 个 ZIP 条目 CRC、中文及空格目录解压、文件哈希与 60 个应用模块源码绑定检查通过。

预设界面使用实际 Qt 控件和临时数据在离屏环境检查，未操控用户桌面或个人设置。
**本轮没有完成 Roblox 实时聊天、NVIDIA 录制、真独占全屏、物理多屏混合 DPI 或干净 Windows 系统的实机验收。**
普通长句仍可能重复、漏译或错译，扩展语义关键词范围仍为 4/8；小写 `l8r` 仍可能被 OCR 误识别。
显示器坐标有效不代表游戏窗口位置或界面缩放未变，切换场景后应检查选区。真独占全屏可能无法显示普通悬浮字幕，优先尝试无边框窗口。
