本轮改进聊天消息分行、部分多词昵称保护，以及已确认短回复组合，例如 `ty np lol` → `谢谢，没问题，哈哈`。仍使用原有轻量中英模型及日语模型，没有加入试验性大模型或额外下载服务。

这不是通用 Roblox 口语翻译质量已经解决的版本。复杂缩写、游戏术语和省略句仍可能错译，尚未完成真实 Roblox、NVIDIA 录屏、独占全屏或全新 Windows 系统验收。

## 改了什么

- 两条带昵称消息保持分开；只在 OCR 位置明确支持时，合并同一消息的缩进续行。
- 逐行模式保护部分两到三个首字母大写的英文显示名，不送入模型、不参与中英方向判断。关闭词表时仍可保护昵称，但不展开缩写。
- 两到五个已确认的独立短回复可组合显示；包含未知词、否定句、普通句子或自定义覆盖时，不套用组合规则。
- 缓存包含处理策略；停止、清空、设置变化或出现新文字后，过期结果不显示、不写缓存。
- 新增仅使用生成图片的聊天自检，不读取玩家屏幕。

原来的单独 `ty`、`np` 本来已能正确翻译，不算本轮新增成果。

## 测了什么，没测什么

最新源码回归 **4247 项通过、10 项跳过**。完成生成图片上的真实本地 OCR、52 条构造文本的实际轻量模型对照、本机 EXE 自检，以及重新解压后的 711 文件逐项校验和聊天自检。构造样例不代表整体准确率；重叠的重点测试不再额外累加。

复杂口语仍有误译，包括复活指令遗漏、生命值被误作时间、缺失撇号被误解、出生点或 clutch 按字面翻译等。更大的离线候选也没有通过质量评估，因此没有装进运行包。没有对其他电脑或所有游戏作运行与准确性保证。

42 个模型文件、282 个运行依赖文件、125 个许可文件与原已审查运行包逐字节一致。旧版本及正式 v0.1.0 保留不动，本次独立标为 prerelease，不替换正式最新版。
