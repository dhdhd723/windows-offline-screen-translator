# Windows 本地屏幕中英翻译器：实现方案

当前实现是单进程 Windows x64 桌面程序。Python 3.12 负责协调，PySide6 Widgets 负责托盘、框选、设置和悬浮字幕；Win32 API 负责显示器坐标、全局热键、置顶且不抢焦点的窗口样式。MSS 截取固定区域。OCR 使用 RapidOCR 调用 PP-OCRv5 mobile 的 ONNX 模型；翻译使用两个 OPUS-MT 模型，经 CTranslate2 转换与 INT8 量化，以 SentencePiece 分词。选择这组组件是为了让推理在本机 CPU 上运行，同时保持 Windows 集成和打包复杂度可控。模型来源：[PP-OCRv5](https://www.paddleocr.ai/main/en/version3.x/algorithm/PP-OCRv5/PP-OCRv5.html)、[英译中](https://huggingface.co/Helsinki-NLP/opus-mt-en-zh)、[中译英](https://huggingface.co/Helsinki-NLP/opus-mt-zh-en)。

模型取舍：PP-OCRv5 mobile 比完整 Paddle 推理栈更容易打包、占用较小，适合清晰中英字幕；对小字、艺术字体和运动背景仍可能误识别。两个方向专用 OPUS-MT INT8 模型无需大语言模型运行环境，CPU 开销较低，但专业术语、口语和上下文翻译不保证准确。方向可手动固定；OCR 置信度不能当作翻译正确率。当前不引入 GPU、付费 API 或系统 OCR 语言包依赖，降低部署门槛。

开发顺序：MVP 先打通单区域截图、OCR、双向翻译和快捷键字幕；稳定版再补变化门控、缓存、任务作废、DPI、托盘、设置和打包回归（本次已实现，真实混合 DPI 与长测仍需验收）；完整版才考虑 DXGI、跨屏/多区域、字幕历史和可选高质量模型包。每阶段保持无网运行和普通用户无需 Python，不把扩展功能拖进当前核心链路。

数据流很短：

```text
框选的物理像素区域 → MSS 截图 → 图像指纹/防抖 → 单帧邮箱
                                           ↓
悬浮字幕 ← Qt 信号 ← 翻译/精确缓存 ← 语言方向与文本去重 ← OCR
```

Qt 主线程只处理事件、快捷键和界面。一个捕获线程拥有 MSS 实例，按设置频率截图；一个推理线程依次运行 OCR、归一化、翻译与模型预热。邮箱只保留最新待处理帧，避免模型忙时排队翻译过时画面。每次启停或清空递增 `generation`；旧任务完成后不得发布。用户清空动作先停止监控再清空；显式恢复会建立新观察，同一句可重新翻译。流水线内部清空仍保留原句抑制机制，防止在途旧结果回流。图像侧结合缩小灰度图、边缘和精确像素摘要，在文字框附近优先检测，并给框外新文字留稳定帧复查；文字侧做归一化和相似度判断。短文本、数字变化不会因模糊匹配被忽略，长句的极小变化需要再次确认。空白画面经两次 OCR 确认后清字幕。

快捷键编辑只接收设置控件焦点内的键盘事件，不安装键盘记录钩子。录入期间释放本程序的全局快捷键并暂停 Esc；结束后用短周期定时器等待相关键松开，再恢复最新设置的注册，避免误触发。具体操作见 [快捷键交互修订说明](快捷键交互修订说明.md)。

翻译缓存以“归一化规则版本＋模型标识＋方向＋完整原文”的摘要为键，只做精确命中。默认最多 2,000 条内存 LRU；用户开启选项后才使用 SQLite，关闭选项不会自动删除已有数据库。默认不保存截图。配置在 `%LOCALAPPDATA%\ScreenTranslator\config.json`，JSON 原子替换写入。

主要目录职责如下：

| 路径 | 职责 |
|---|---|
| `src/screen_translator/application.py`、`contracts.py`、`paths.py` | 程序入口与状态连接、跨模块数据对象、运行和模型路径。 |
| `src/screen_translator/core/`、`capture/` | 流水线状态与任务作废、文字变化判断、MSS 截图和图像门控。 |
| `src/screen_translator/inference/` | RapidOCR、CTranslate2 模型装载、SentencePiece 分词与分段。 |
| `src/screen_translator/platform/windows/`、`ui/` | DPI/显示器/热键/窗口样式，以及框选、托盘、字幕和设置界面。 |
| `src/screen_translator/storage/` | 配置与内存/可选磁盘缓存。 |
| `models/`、`packaging/`、`tools/`、`tests/` | 固定版本模型与校验清单、打包配置、模型准备和诊断工具、自动测试。 |

进程在创建 Qt 窗口前启用 PerMonitorV2；内部区域、鼠标与屏幕抓取统一使用物理像素，Qt 坐标在界面边界转换。当前可在任一显示器内框选，但单个区域必须完整落在同一块屏幕。显示器拓扑变化会使旧区域失效并要求重选。字幕窗使用 Win32 置顶、半透明、无激活与鼠标穿透样式；优先放在框外，并尝试 `WDA_EXCLUDEFROMCAPTURE`。若系统不支持截图排除且字幕与捕获区域重叠，程序隐藏字幕，译文仍可从托盘复制，避免画面反馈循环。Alt+R 被占用时依次尝试 Alt+Shift+R、Ctrl+Alt+R；Esc 在监控期间通过低频键盘状态轮询观察，不拦截原应用按键。

交付使用 PyInstaller onedir：exe、运行组件与 `models/` 同目录分发，不要求用户安装 Python。PyTorch 和 Transformers 只参与模型准备，不进入运行包；启动时模型按需加载，模型清单记录版本及 SHA-256。分发时保留模型与第三方组件的许可证和署名。当前范围覆盖单显示器内的固定区域、持续翻译、悬浮字幕、托盘和持久配置；下一阶段应优先做不同 DPI/游戏画面的人工测试、长时间运行与干净机器打包验收。DXGI、跨屏选区和更大模型属于后续扩展。自动测试和合成画面基准不能替代这些硬件场景的验收，也不能保证特定字幕的译文质量或延迟。
